Abstract

This project compares different machine learning approaches for image classification tasks. We evaluate several methods including KNN with HOG features, Random Forest, and hybrid approaches that combine traditional and deep learning techniques like CNN+KNN and XGBoost+CNN. Our results show that hybrid approaches perform better than traditional methods alone, with CNN+KNN and XGBoost+CNN achieving 44.7% and 44.5% accuracy respectively.

Problem Statement

This research investigates the effectiveness of various machine learning approaches for image classification tasks, with a focus on hybrid methods that combine traditional and deep learning techniques. Our main goal is to determine which approaches offer the best performance in terms of classification accuracy, computational efficiency, and model interpretability.

Key research questions include:

  • How do traditional feature extraction methods compare to representations learned from CNNs?
  • Can hybrid models combine the strengths of both traditional machine learning and deep learning?
  • How do different approaches perform with varying amounts of training data and computational resources?

Approaches

Traditional Approaches

KNN with HOG Features: Using Histogram of Oriented Gradients features with k-Nearest Neighbors classification algorithm. Images were divided into 8×8 pixel cells, with gradient magnitude and orientation computed for each pixel.

Random Forest: Using color and texture features including color space histograms, Local Binary Patterns, Haralick texture features, and Hu moments for shape characterization.

Hybrid Approaches

CNN with Naive Bayes: Using ResNet50 for feature extraction, then discretizing the features into 10 equal-frequency bins for a Multinomial Naive Bayes classifier.

XGBoost with CNN Features: Using ResNet50 for feature extraction with feature standardization, then applying XGBoost classifier with optimized hyperparameters.

CNN with KNN: Using ResNet50 for feature extraction, applying dimensionality reduction to 50 features, then using k-Nearest Neighbors with cosine similarity and distance-weighted voting.

Experimental Setup

We conducted our experiments on the Caltech-101 dataset, containing 9,144 images across 101 object categories and a background class.

Data preprocessing steps included:

  • Resizing all images to 128×128 pixels while preserving aspect ratio
  • Normalizing pixel values to the range [0, 1]
  • Splitting the dataset into training (70%), validation (15%), and test (15%) sets
  • Using stratified sampling to maintain class distributions across splits

Key Findings

  • Hybrid approaches consistently outperform traditional machine learning and standalone methods.
  • CNN+KNN and XGBoost+CNN achieved the highest accuracies (44.7% and 44.5%).
  • Traditional feature engineering still provides value when combined with appropriate classifiers.
  • Different approaches present important trade-offs between accuracy, training time, inference speed, and model size.
  • CNN feature extraction proved more effective than hand-crafted features like HOG.

Error Analysis

Our detailed error analysis revealed several patterns in misclassifications:

  • Visual Similarity Confusion: Similar categories (bird species, vehicle types) were frequently confused.
  • Intra-class Variation: Categories with high internal variation posed significant challenges.
  • Training Data Imbalance: Underrepresented classes showed substantially higher error rates.
  • Background Interference: Complex backgrounds sometimes distracted the models from the primary object.
  • Scale and Occlusion Issues: Partially occluded or unusually scaled objects had higher misclassification rates.

Hand-drawn Sketch Recognition

Sonic Vyas, Yash Kumar Singh, Shardul Vikram Singh, Sarthak Bhiwaji Kolekar, Shlok Kanani

CSL2050: Pattern Recognition and Machine Learning, Indian Institute of Technology Jodhpur

Hand-drawn sketch recognition is an important problem in pattern recognition and machine learning, as sketches provide a natural form of human expression. In this project, we explore different machine learning models for classifying sketches into object categories. We have implemented k-Nearest Neighbors (kNN) and Support Vector Machine (SVM) models and evaluated their performance on a dataset of 20,000 unique sketches across 250 categories.

Overview

Hand-drawn sketch recognition is a challenging problem due to the high variability in sketching styles across different individuals. Our project focuses on implementing and comparing traditional machine learning approaches for sketch classification, with plans to extend to more advanced techniques. The dataset consists of 20,000 unique sketches drawn by non-experts across 250 categories, making it a comprehensive test bed for our algorithms.

Dataset

The dataset contains 20,000 unique sketches spread across 250 object categories (animals, everyday objects, vehicles, etc.). These sketches are drawn by non-experts, making them highly variable in style. The dataset provides a large-scale exploration of human sketches and their distribution across different object categories.

Example sketches from the dataset

Methods

k-Nearest Neighbors (kNN)

We implemented kNN for classification and experimented with different values of k ranging from 3 to 28. The implementation includes:

  • Distance metric: Manhattan distance
  • Feature extraction: HOG, LBP, and edge density features
  • Feature normalization using MinMaxScaler

Support Vector Machine (SVM)

We implemented SVM with different kernels and hyperparameters, including:

  • Different kernel functions (linear, RBF)
  • Various C values (1.0, 10, 100)
  • Dimensionality reduction using PCA with different numbers of components

Results

kNN Results

The highest accuracy achieved was 27.82% when k=15.

We experimented with different values of k ranging from 3 to 28, and found that k=15 gave the best balance between overfitting and underfitting.

SVM Results

The highest accuracy achieved was 21.00% with kernel=rbf, C=1.0, and using PCA with 150 components.

Future Work

To improve accuracy, we plan to implement additional techniques:

  • Decision Trees for simple and interpretable classification
  • Gaussian Mixture Models (GMM) for probabilistic clustering and classification
  • Convolutional Neural Networks (CNN), as deep learning approaches have been successful in image classification problems
